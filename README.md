# 盗聴と暗号体験

高校「情報Ⅰ」で、盗聴の危険と暗号化の仕組み（シーザー暗号・公開鍵暗号・鍵配送問題）を体験するWeb教材です。インストールは不要で、ブラウザで開くだけで使えます。

**使うページ：** https://takanari-k-creator.github.io/crypto-taiken/

姉妹教材：[クライアントサーバ体験](https://takanari-k-creator.github.io/client-server-taiken/) ／ [P2P体験](https://takanari-k-creator.github.io/p2p-taiken/)

## 使い方
3人1組で、次の3つの役割に分かれます。

| 役割 | できること |
|---|---|
| 📤 送信者 | 暗号方式を選んで、メッセージを暗号化して送る |
| 📥 受信者 | 届いたメッセージを、自分の鍵で復号して読む |
| 🕵️ 盗聴者（ルータ役） | 送信者と受信者の通信を中継する。通り道のデータは全部見え、解読を試せる |

## 3つの暗号方式
| 方式 | 盗聴者は読める？ | 気づくこと |
|---|---|---|
| ① 暗号化なし | そのまま読める | 通り道の誰にでも読まれる |
| ② シーザー暗号 | 総当たりですぐ解ける | 鍵の種類が少ないと弱い。鍵を相手にどう渡すか（鍵配送問題） |
| ③ 公開鍵暗号（RSA） | 公開鍵を盗んでも読めない | HTTPS（🔒マーク）の仕組みにつながる |

## 注意
- ③は、ブラウザに組み込まれた本物の暗号（RSA-OAEP 2048ビット）を使います
- IPアドレスは教材の中だけで使う仮想のもので、端末の本物のIPアドレスではありません
- 端末どうしの通信には WebRTC（PeerJS）を使います。最初の接続だけ、PeerJS の公開仲介サーバを使います
- メッセージはどこにも保存されません。ページを閉じると消えます
- 校内ネットワークの設定によっては接続できないことがあります。授業の前に、数台でテストしてください
